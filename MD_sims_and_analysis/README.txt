The .dcd source files for the structural analysis are too large to share.
They are NOT included in this directory and must be generated by running the
trajectory (trj) jobs before any TRAVIS analysis can be done.

Generating the .dcd files
-------------------------
Each .dcd is written by the production stage of lmp_trj.in.
All required inputs (*_annealed.data,*_system.in.settings, lmp_trj.in, 
lammps_trj_job.sh) are already present in each 313 folder.
To generate them, submit the trj job from that folder:

  cd Mixture\313   ->  sbatch lammps_trj_job.sh   (produces mixid_977.dcd)
  cd Pure\313      ->  sbatch lammps_trj_job.sh   (produces mixid_983.dcd)

Notes:
- lammps_trj_job.sh calls ../../ensemble_averager_cli.py to compute the
  equilibrium box length. Make sure to copy Mixture\313\ensemble_averager_cli.py to the
  top-level directory first, or set L directly in the job script to the values
  used in the original runs: Mixture L=39.985042, Pure L=40.060769.
- Running the job overwrites the existing *_trj.log, *_trj_thermostyle.txt,
  *_trj_equil_thermo.txt and *.1000000.restart files.

Running the analysis
--------------------
To run structural analysis with TRAVIS, either copy each generated .dcd file
to the relevant analysis subfolders listed below, or modify the TRAVIS input
files to point to the source .dcd files.

Mixture
Source: Mixture\313\mixid_977.dcd
Destinations:
- Mixture\313\cdf\mixid_977.dcd
- Mixture\313\rdf\mixid_977.dcd
- Mixture\313\rdf_H_O\mixid_977.dcd

Pure
Source: Pure\313\mixid_983.dcd
Destinations:
- Pure\313\cdf\mixid_983.dcd
- Pure\313\rdf_O_H\mixid_983.dcd
